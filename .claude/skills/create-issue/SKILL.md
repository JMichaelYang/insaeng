---
name: create-issue
description: Use when the user wants to file new work, a bug, or an idea as a GitHub issue in the current repo.
---

1. Draft a short imperative title and a body following [references/template.md](references/template.md) exactly; respect its length limits.
2. Create it: `gh issue create --title "<title>" --body-file <file>`.
3. Reply with the issue URL.
